# Prueba: guardar y cargar partida — 2026-10-18

**Objetivo del dueño:** cerrar el guardado y la carga del recorrido 1:1.

## Cómo se probó

`tools/guardado.py` (`make guardado`, `make guardado-eu`), con el binario
libre (el código del APK) y una tarjeta nueva (`AC3_CARD`). Se usa el
registro de la capa de tarjeta (`PSX_CARDDBG=1`), que anota cada llamada
del juego.

1. **Guardar** en una partida nueva:
   - interfaz de la UPEO, antes de la primera misión: icono **SAVE**, a dos
     pulsaciones a la derecha de MISSION;
   - "Save game?" → yes;
   - "No files found on MEMORY CARD. Save new file?" → yes;
   - archivo 1;
   - "Save to file #1?" → con el cursor arriba, "yes". El cursor empieza en
     "no", y por eso los primeros intentos volvían a la elección de archivo
     sin guardar.
2. **Cargar**, en otra partida con una **copia** de esa tarjeta: menú
   principal → **load** → archivo 1 → confirmar.
